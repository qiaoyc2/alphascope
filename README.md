# AlphaScope

AlphaScope is a Python project for an autonomous financial research agent that will investigate stock questions using traceable evidence. The current milestone establishes validated research models and state operations; research tools and the agent loop will follow in later milestones.

Requires Python 3.11 or newer.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pytest
```

Milestone 1 has no required environment variables or live research command.
